# OR-45: repeated-array numbers in multipart bodies use Rust formatting

TypeScript: `packages/ai/src/route/media.ts:471-476` encodes a multipart body with `HttpClientRequest.bodyFormData`, and repeated text fields come from `MediaInput.appendFields` (`packages/ai/src/protocols/utils/media-input.ts:90-94`): a scalar array appends one part per item named `key[]` or `key` through `String(item)` (`:92-93`), while a single value is appended as-is or as `encodeJson(value)` (`:94`). The repeated sites are the OpenAI transcription route with `repeatArrays: "key[]"` for `languages` and `timestamp_granularities` (`packages/ai/src/protocols/openai-transcription.ts:187-204`) and ElevenLabs transcription with `repeatArrays: "key"` (`packages/ai/src/protocols/elevenlabs-transcription.ts:119-130`). `String` is the ECMAScript `ToString` algorithm, so every JavaScript number is spelled the way JavaScript prints it (pinned commit `e54fbacb3d3aebc85f0e5ada0a5c490cc9333a91`).

Rust: `append_fields` repeats an all-scalar array only when `repeat_arrays` is set (`crates/ai/src/media/multipart.rs:98-113`), naming parts `key[]` or `key` (`:104-105`) and formatting each item with `scalar_text` (`:109`), defined at `:126-131` as the string as-is and anything else through serde_json's `Value::to_string()` (`:129`). Non-repeated fields keep the string or `crate::json::encode_body` (`:114-118`), so `scalar_text` is reached only for repeated arrays. Its callers are `crates/ai/src/protocols/openai_transcription.rs:220-228` (`RepeatArrays::Brackets`) and `crates/ai/src/protocols/elevenlabs_transcription.rs:108-116` (`RepeatArrays::Key`).

Reason: serde keeps a JSON number's kind, so a value that arrived as `1.0` prints `"1.0"` where JavaScript's `String(1)` gives `"1"`; `-0.0` prints `"-0.0"` where JavaScript gives `"0"`, and exponent thresholds and spellings can differ (`0.000001` prints `"1e-6"` where JavaScript gives `"0.000001"`). This is reachable only through a caller-supplied numeric provider option or `http.body` field in a repeated position. No cassette sends a non-integer number in a repeated multipart field: the corpus's only repeated fields are the string `languages[]`, `timestamp_granularities[]` and fixture `tag[]`/`tag` arrays, so recorded request bytes still match.
