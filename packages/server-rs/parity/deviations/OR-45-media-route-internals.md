# OR-45: queued media result decoders take an injected clock, and result assets carry download headers but no middleware

TypeScript: `packages/ai/src/route/media-protocol.ts:93-108` defines `PollContext<Token>` as `token`, `credentials` and `get`, with no clock; `result.decode` (`:138-144`) is an `Effect` that reads the ambient `Clock` when it needs the time, as `MediaProtocol.expiringUrl` does at `:316-319`. `credentials(url)` resolves to `Pick<Media.AssetOptions, "headers" | "middleware">` in `packages/ai/src/route/media.ts:212-217`, and protocols spread that into `Media.url`, so a `url` asset carries both and downloads with the caller's middleware through `Media.Asset.bytes` (`packages/ai/src/media.ts:151-166`, `:271-281`). `Asset.Input.headers` and `Asset.Input.middleware` are runtime-only in both implementations: `AssetEncoded`, `toJSON` and `AssetSchema` omit them (`:192-199`, `:212-229`, `:233-256`).

Rust: `crates/ai/src/media/route.rs:590-596` gives `PollContext` a `clock: Arc<dyn Clock>` beside `token`, `get` and `credentials`; the context is built from the execution clock at `:834-835`, and `result_decode` returns a `BoxFuture` that is awaited at `:869` (`:624-629`) instead of an `Effect`. Protocols read that clock to stamp an `expiresAt`: Seedance uses `task.updated_at * 1000 + retention` when the task has one and falls back to `context.clock.now_ms() + retention` (`crates/ai/src/protocols/seedance_video.rs:224-241`), and MiniMax Hailuo uses `context.clock.now_ms() + retention` (`crates/ai/src/protocols/minimax_video.rs:454`); both match the pinned fallbacks (`packages/ai/src/protocols/minimax-video.ts:350` stamps the Hailuo URL, while `:280-288` leaves the H3 URL without an expiry, as the Rust H3 decoder does). `credentials` returns `Option<StringMap>` headers only (`:594`), so an asset built by `url_asset` (`crates/ai/src/protocols/utils/media_input.rs:183-196`) has no equivalent of the TypeScript runtime-only `middleware`. A queued image or video route whose start returns a non-string job token fails with `InvalidProviderOutput` (`crates/ai/src/modalities/image.rs:368-393`, `crates/ai/src/modalities/video.rs:232-254`), where the pinned clients treat the same case as a defect through `Effect.orDie` (`packages/ai/src/image-client.ts:27`, `packages/ai/src/video-client.ts:18`).

Reason: Rust protocol decoders are plain functions with no ambient Effect environment, so time is threaded through `PollContext` and the poll context keeps the final URL next to the response (`CallResponse` at `:213-216`) for error `HttpContext`; headers-only credentials mean a caller downloading a result asset applies its own middleware or none, and the crate exposes no asset download method that would apply the TypeScript one. Replay compares request bytes and decoded results, so it covers the headers path through `download_video_asset` (`crates/ai/tests/all/replay.rs:558-588`) but never a download that needs middleware, and the MiniMax cassettes cover the expiring Hailuo URL and the non-expiring H3 URL.
