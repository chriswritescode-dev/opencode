# OR-38: the strict round-trip corpus skips samples with unpaired UTF-16 surrogates

TypeScript: the server carries JSON bodies as JavaScript strings, and ECMAScript `JSON.parse` accepts an unpaired surrogate escape such as `"\ud800"` that `JSON.stringify` writes back unchanged, so a TypeScript client and server exchange such a value end to end. The TypeScript server only guards against that where a strict JSON parser sits behind it: `packages/core/src/shell.ts:1247` calls `toWellFormed()` on a span command because "strict OTLP JSON parsers reject a lone surrogate, which a cut through an emoji would leave" (pinned commit `73a0eae88de47f10068a0f9dc7a743638fa3d830`). The TypeScript side of the corpus, `packages/server-rs/script/gen/corpus.ts`, samples error schemas with `Arbitrary` and therefore produces such values too.

Rust: `serde_json` rejects an unpaired surrogate while parsing a JSON string, so `crate::codec::round_trip` in `crates/contract/src/codec.rs:77` cannot consume every fixture the TypeScript generator would otherwise write. `script/gen/corpus.ts` drops each sampled value, and each invalid mutation, whose encoded form contains an unpaired UTF-16 surrogate before writing `crates/contract/tests/corpus/schemas.json`, and reports the skipped count per root so no root disappears silently.

Reason: `serde_json` decodes JSON strings into UTF-8 `String`, where an unpaired surrogate has no representation and RFC 8259 forbids it, while JavaScript strings are UTF-16 and `JSON.parse` accepts it. The strict round-trip corpus in `crates/contract/tests/corpus/schemas.json` and `crates/contract/tests/corpus/requests.json` is the parity check that covers every root in both files (errors, events, IDs, responses and requests); it deliberately omits the unpaired-surrogate cases rather than asserting a Rust result for input this package cannot represent. The server-visible consequence is that a JSON request body containing an escaped unpaired surrogate, such as `"\ud800"`, is rejected by the Rust server with a decode error while the TypeScript server accepts it. Correctly paired surrogates, including all astral characters such as emoji, are unaffected and stay in the corpus.
